# Profile Review Checklist

Use this before updating the public GitHub profile README.

- Keep featured projects limited to work that is currently active or representative.
- Verify project names, links, versions, and status claims before publishing.
- Prefer concise technical summaries over marketing-heavy copy.
- Keep mobile readability in mind for badges, tables, and long lines.
- Avoid exposing local paths, keys, private repository details, or unfinished claims.
- Make sure new sections add useful context rather than visual noise.

The profile should quickly explain what is being built and where to inspect it.
