Plex is a compact coding-model project built from **randomly initialized weights** rather than starting from a pretrained coding model.

The goal is not a general chatbot. It is a focused implementation engine for understanding narrowly scoped repository tasks and producing the smallest correct change.

### 📊 Current research model

| | Current state |
|---|---|
| **Model** | Plex Nano |
| **Parameters** | 27,566,080 |
| **Context window** | 512 tokens |
| **Training** | From scratch |
| **Primary scope** | HTML, CSS, JavaScript |
| **GPU training** | CUDA |
| **CPU generation** | Working |
| **Phase** | Phase 2 — active research |

### 🌐 Current training direction

**Plex Web** moves the project toward:

```text
permissively licensed HTML / CSS / JavaScript
                    ↓
             domain pretraining
                    ↓
          task-format fine-tuning
                    ↓
        structured repository edits
```

### ⚙️ Intended workflow

```text
TASK
  ↓
INSPECT REPOSITORY
  ↓
FIND RELEVANT FILES
  ↓
BUILD FOCUSED CONTEXT
  ↓
PLAN THE SMALLEST CORRECT EDIT
  ↓
VALIDATE
  ↓
RETURN A CLEAN DIFF
```

### 🧩 Two-layer architecture

| Layer | Responsibility |
|---|---|
| **Plex Nano** | Semantic understanding, edit intent, target classification, structured planning, training, and evaluation |
| **Plex Code** | Deterministic repository scanning, exact source resolution, validation, mutation safety, and diff generation |

> [!IMPORTANT]
> Plex is active research. The training stack and repository tooling work, but the model has not yet demonstrated reliable end-to-end general coding ability on unseen tasks.
